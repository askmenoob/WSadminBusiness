# Backup, restore and rollback
`./scripts/backup-db.sh` creates a PostgreSQL custom-format backup without modifying production. `./scripts/restore-db.sh <dump> <fresh-db>` restores only into an explicitly separate database. `./scripts/migration-rehearsal.sh` recreates a disposable database and applies the full migration history. Rollback is restore-first: preserve the failed database, restore the last verified dump to a new database, verify schema/tests, then switch service configuration during a controlled maintenance window. Never destructively downgrade the production schema in place.
